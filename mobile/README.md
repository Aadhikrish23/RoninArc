# RoninArc for Android

The phone app for RoninArc. It uses your RoninArc Cloud account, the same library your PC syncs with (Settings → RoninArc Cloud on the PC).

Built with Expo (SDK 57) and Expo Router. The screens live in `src/app/`, and everything else in `src/`.

## Run it

```bash
npm install
npx expo start            # Expo dev server; press "a" for an Android emulator
```

The app talks to RoninArc Cloud at the address baked in at build time. The default, `http://10.0.2.2:5056`, reaches a cloud backend running on this PC from the Android emulator. To start that backend:

```bash
cd ../backend
CLOUD_MODE=true PORT=5056 MONGO_URI=mongodb://localhost:27017/RoninArc_cloud_dev JWT_SECRET=dev npx ts-node --transpile-only src/server.ts
```

## Build an APK

```bash
RONINARC_CLOUD_URL=https://<your-cloud>.onrender.com npx expo prebuild --platform android --clean
cd android
./gradlew assembleRelease -PreactNativeArchitectures=arm64-v8a,x86_64
# -> android/app/build/outputs/apk/release/app-release.apk
```

On a PC with little free memory, add `--max-workers=1` and skip the release lint checks:

```bash
-x lintVitalAnalyzeRelease -x lintVitalReportRelease -x lintVitalRelease
```

`android/` is generated by `expo prebuild`; don't edit it by hand. Native settings live in `app.config.ts`.

**Signing:** release builds are currently signed with the debug key, which is fine for testing. Before sharing with friends, create a release keystore and keep it safe: every later update has to be signed with the same key, or Android refuses to install it over the old one.

## API types

`src/api/schema.d.ts` is generated from the backend's OpenAPI document. With the backend running on :5000:

```bash
npm run api:types
```
